SAW

Simple Agent Wallet

A focused CLI wallet for agents that pay over HTTP 402 / x402 — EVM, Solana, and Hedera. Inspect. Confirm. Pay.

Install the agent skill

npx skills add AxLabs/simple-agent-wallet --skill saw -g -y

Built for agents that ship payments

SAW keeps keys local, never takes secrets on the CLI, and speaks x402 exact and batch-settlement without scraping truncated payment headers.

Multi-family

EVM (eip155:*), Solana, and Hedera in one wallet file.

x402 native

saw inspect then saw pay --confirm — headers stay inside the tool.

Agent-ready

Skill + plain agents.md / llms.txt for discovery.

Then pay:

saw init
saw inspect https://example.com/paid
saw pay https://example.com/paid --confirm

Neo X Ethereum Polygon Optimism Solana Hedera
